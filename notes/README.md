# Notes

One folder per module, matching [`plan/`](../plan/README.md): `01-networking/`, `02-os-concurrency/`,
`03-databases/`, and so on. Create the folder when you start the module.

For each study session, write a short file (e.g. `03-databases/mvcc.md`) with:
- **In my own words:** the concept explained as if to a junior engineer
- **How it shows up at work:** a real example from Node.js, PHP, Go, or AWS
- **Self-test answers:** your answers to the module's questions, before asking for a review
