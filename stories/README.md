# STAR Stories

Prepare 6–8 stories. One file per story. Each story can usually answer several questions.

**STAR:** Situation (1–2 lines) → Task (your responsibility) → Action (what *you* did, the bulk of the story) → Result (numbers if possible) → Learning.

Keep each to about 2 minutes when spoken.

## Story checklist

- [ ] A hard technical decision / tradeoff
- [ ] A production incident I owned
- [ ] Disagreement with a peer or manager
- [ ] Mentoring or helping someone grow
- [ ] A failure and what I learned
- [ ] Influencing without authority
- [ ] Cutting scope / shipping under a deadline
- [ ] The notification system (ownership + impact)

## Template

```markdown
# <Title>

**Questions this answers:** "Tell me about a time you..."

**Situation:**
**Task:**
**Action:**
**Result:**
**Learning:**
```
