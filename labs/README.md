# Labs

Hands-on builds from each module in [`plan/`](../plan/README.md). One folder per module:
`labs/01-http/`, `labs/03-databases/`, and so on. Go code here is part of the repo's Go module,
so `go test ./...` from the root runs lab tests too.

For each lab, add a short `README.md` in its folder:
- What you built
- What you broke on purpose, and what you observed
- What surprised you

The "what surprised you" notes are excellent material for interview answers.
